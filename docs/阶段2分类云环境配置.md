# 阶段 2 分类云环境配置

本文用于部署预设分类、分类选项和管理员分类管理功能。

## 1. 创建数据库集合

在微信开发者工具的云开发控制台中创建：

- `categories`

权限类型选择“所有用户不可读写”。小程序客户端只通过 `api` 云函数访问分类数据。

## 2. 创建索引

在 `categories` 的“索引管理”中创建：

| 索引名称 | 索引字段 | 唯一 |
| --- | --- | --- |
| `normalized_name` | `normalized_name` 升序 | 是 |
| `status` | `status` 升序 | 否 |

`normalized_name` 由服务端生成，用于保证去除首尾空格并规范化后的名称不重复。
客户端不能提交或修改该字段。

## 3. 部署云函数

在项目根目录执行：

```powershell
npm run build:cloud
```

然后在微信开发者工具中右键 `cloudfunctions/api`，选择
“上传并部署：云端安装依赖”。

## 4. 人工验收

1. 使用管理员或所有者账号进入“仓库工作台”。
2. 打开“分类管理”，首次打开后应显示九个预设分类。
3. 返回并再次进入，预设分类总数仍为九个。
4. 新建“活动器材”，创建成功后应显示在预设分类之后。
5. 再次提交“活动器材”或带首尾空格的“ 活动器材 ”，应只提示“已存在同名分类”。
6. 将“活动器材”重命名为“体育器材”，分类 ID 应保持不变。
7. 停用“体育器材”后，管理页仍显示该分类及“已停用”状态。
8. 重新启用后，状态恢复为 `ACTIVE`。
9. 预设分类不显示重命名、停用按钮。
10. 普通 `MEMBER` 首页不显示“分类管理”入口，且直接调用管理接口会被拒绝。
11. 普通成员在后续物品登记页面中仍可选择分类或新建分类。
12. 未通过审核或已停用账号不能查询或新建分类。

分类不提供物理删除。物品登记、分类检索和管理员调整物品分类将在物品批次实现。
