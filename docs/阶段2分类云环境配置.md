# 阶段 2 分类云环境配置

本文用于部署预设分类、分类列表和新建分类功能。

## 1. 创建数据库集合

在微信开发者工具的云开发控制台中创建：

- `categories`

权限类型选择“所有用户不可读写”。小程序客户端只通过 `api` 云函数访问分类数据。

## 2. 创建索引

在 `categories` 的“索引管理”中创建：

| 索引名称 | 索引字段 | 唯一 |
| --- | --- | --- |
| `normalized_name` | `normalized_name` 升序 | 是 |
| `status` | `status` 升序 | 否 |

`normalized_name` 由服务端生成，用于保证去除首尾空格并规范化后的名称不重复。
客户端不能提交或修改该字段。

## 3. 部署云函数

在项目根目录执行：

```powershell
npm run build:cloud
```

然后在微信开发者工具中右键 `cloudfunctions/api`，选择
“上传并部署：云端安装依赖”。

## 4. 人工验收

1. 使用已通过审核的账号进入“仓库工作台”。
2. 打开“物品分类”，首次打开后应显示九个预设分类。
3. 返回并再次进入，预设分类总数仍为九个。
4. 新建“活动器材”，创建成功后应显示在预设分类之后。
5. 再次提交“活动器材”或带首尾空格的“ 活动器材 ”，应提示已存在同名分类。
6. 普通 `MEMBER` 账号可以新建分类。
7. 未通过审核或已停用账号不能查询或新建分类。

本批次不提供分类删除或停用入口，也不包含物品登记和图片上传。
