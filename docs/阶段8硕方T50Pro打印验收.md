# 阶段 8：硕方 T50 Pro 打印验收

## 当前实机记录

- 已确认至少一台手机能够发现并连接 T50 Pro；
- 已成功打印 30 mm × 30 mm 微信小程序码标签；
- 已确认打印标签能够扫码打开对应物品；
- iOS/Android 双平台、异常恢复和连续 20 张压力测试尚未验证。

## 1. 当前边界

客户端已经接入硕方原生微信小程序 SDK，支持搜索、连接、断开和打印 30 × 30 mm
小程序码标签。自动化测试只能验证参数、状态和错误转换，不能代替真实打印机验收。

本阶段不需要重新部署云函数；标签 PNG 仍使用已经部署的 `api` 云函数和云存储结果。

## 2. 本机准备

1. 确认官方压缩包位于：
   `%LOCALAPPDATA%\Temp\SupvanT50ProWeChat.zip`。
2. 在项目根目录执行：

   ```powershell
   npm run install:supvan-sdk
   npm run check
   ```

3. 使用微信开发者工具重新编译小程序。
4. 确认 T50 Pro 已装入 30 × 30 mm 间隙热敏标签纸并开机。

SDK 目录被 Git 忽略，不会随公有仓库提交；安装脚本会校验固定 SHA256，文件不匹配时会停止。

## 3. 首次真机打印

1. 使用真机打开一个状态为“在库”的物品详情。
2. 点击“查看小程序码”。
3. 确认小程序码图片正常显示，点击“搜索打印机”。
4. 首次使用时允许蓝牙权限。
5. 在搜索结果中选择 T50 Pro；设备名称应与打印机显示或机身信息一致。
6. 连接成功后保持打印份数为 `1`，点击“打印标签”。
7. 只有 SDK 返回完成结果后，页面才显示“打印完成”。
8. 立即用微信“扫一扫”扫描实体标签，确认打开正确物品详情。

## 4. 参数验收

首轮代码参数如下：

| 参数 | 初始值 |
|---|---:|
| 标签宽度 | 30 mm |
| 标签高度 | 30 mm |
| 纸张类型 | 间隙纸（`1`） |
| 标签间隙 | 3 mm |
| 打印浓度 | 4 |
| 打印速度 | 30 mm/s |
| 水平偏移 | 0 mm |
| 垂直偏移 | 0 mm |

实机检查：

- 小程序码四周完整，无明显裁切或非等比拉伸；
- 图案居中，留白均匀；
- 标签不连续跳纸；
- 正常光线下 15～30 cm 能稳定识别；
- 打印浓度不会造成细线粘连或浅到断线。

如果需要调整浓度、间隙或偏移，先记录打印机型号、手机系统、标签纸实际尺寸和样张现象，
再修改固定参数，不能只凭模拟器预览判断。

## 5. 异常与连续打印

依次验证：

- 手机蓝牙关闭；
- 拒绝蓝牙权限后重新授权；
- 打印机未开机或超出距离；
- 连接后关闭打印机；
- 打开耗材仓盖；
- 未装标签纸或标签纸用完；
- 同一标签打印 `2` 份；
- 连续打印不少于 20 张。

任何异常都应显示明确错误，不能显示虚假成功。重复打印不得创建新物品、新公开编码或新标签绑定。

## 6. 通过条件

- iPhone 和 Android 微信客户端均能发现并连接 T50 Pro；
- 单张、多份和连续 20 张打印均完成；
- 30 × 30 mm 标签无不可接受的裁切、偏移或跳纸；
- 实体小程序码能稳定进入正确物品详情；
- 仓盖、耗材、蓝牙和断连错误提示与真实状态一致。
