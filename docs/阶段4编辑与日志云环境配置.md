# 阶段 4：编辑、版本冲突与操作日志云环境配置

本批次包含成员编辑物品、乐观锁冲突返回、操作日志查询和编辑页冲突对比。
离库申请、管理员审核和提醒不在本批次内。

## 1. 部署前检查

在项目根目录执行：

```powershell
npm run build:cloud
```

在微信开发者工具中上传并部署 `cloudfunctions/api` 云函数，确认部署的是最新代码。
小程序端代码也要重新编译后再验收。

## 2. 数据库索引

`item_operation_logs` 集合需要确认以下索引：

| 索引名称 | 索引字段顺序 | 字段升降序 | 唯一 |
| --- | --- | --- | --- |
| `item_created_at` | `item_id`、`created_at` | `item_id` 升序、`created_at` 降序 | 否 |

该索引用于按物品查询日志并按操作时间倒序展示。不要设置为唯一索引。

## 3. 人工验收

1. 以已审核成员打开一个在库物品，进入“编辑物品”，修改名称或详情并填写 1–250 个字符的提交梗概，保存后确认版本号加一。
2. 在 `item_operation_logs` 中确认新增一条 `UPDATE` 日志，包含操作人、时间、提交梗概、版本前后值，不包含字段修改前后内容。
3. 在详情页进入“查看操作日志”，确认可以看到登记和编辑记录，且页面不提供编辑或删除日志的入口。
4. 用两个客户端同时打开同一版本：客户端 A 先保存；客户端 B 再保存时应收到版本冲突，并看到本地草稿与最新版的差异。
5. 在冲突页分别选择“保留本地”或“使用最新版”，点击“以当前选择继续编辑”，确认基线版本更新后可再次保存；系统不能静默覆盖最新版。
6. 将图片替换、删除或新增后保存，确认最多保留两张图片；保存失败时新上传文件会被清理。

## 4. 已知限制

- 物品分类、标签编码、登记人、登记日期、状态和历史日志不能通过普通编辑页修改。
- 已离库物品由后续离库阶段统一禁止编辑；当前离库审批接口尚未实现。
- 硕方 T50 Pro 打印 SDK 不影响本批次功能。
