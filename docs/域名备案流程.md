# 域名 ICP 备案流程

本项目服务器在中国大陆（腾讯云，111.229.164.241），域名必须完成 ICP 备案后才能用于
小程序后端（微信合法域名要求 HTTPS + 已备案域名）。

## 要点

- 只需办**一次 ICP 备案**，没有单独的"服务器备案"。
- 备案对象是**域名**，但必须通过**服务器接入商**（腾讯云）提交，提交时把
  「域名 + 服务器 + 主体身份」绑定在一起。
- 备案期间域名不能正常使用，服务器上的其他工作不受影响。

## 前置条件

- 已注册域名（腾讯云或其他注册商均可）。
- 用于备案的腾讯云服务器**剩余购买时长 ≥ 3 个月**，不足会被备案系统拦下，
  需要先续费凑够时长。
- 备案主体证件：个人备案用身份证，企业备案用营业执照。
- 域名实名认证信息需与备案主体一致；新注册域名的实名信息同步到管局系统约需
  2～3 天，之后才能提交备案。

## 流程（腾讯云）

1. 腾讯云控制台 →「ICP 备案」→ 按引导用腾讯云助手小程序提交（全程线上）。
2. 填写主体信息、网站信息，选择本服务器（111.229.164.241）。
3. 腾讯云初审（约 1～2 天），期间可能电话核验，注意接听。
4. 初审通过后提交管局审核（约 1～3 周，各省管局速度不同）。
5. 审核通过，收到备案号（格式：京ICP备XXXXXXXX号-1）。

## 备案通过后

1. 域名 A 记录解析到 111.229.164.241。
2. 按 `~/sthmoving/DEPLOY-STATUS.md`（服务器上）执行收尾部署，或按
   [自建后端部署](./自建后端部署.md) 走完剩余步骤。
3. 备案号下来后 **30 天内**办理**公安备案**：
   - 平台：公安部互联网站安全管理服务平台（beian.mps.gov.cn，以官方最新地址为准）
   - 纯线上、免费，通常几天内完成。
4. 小程序页面底部需展示 ICP 备案号并链接到工信部备案系统（微信审核要求）。

## 时间预估

| 环节 | 耗时 |
|---|---|
| 域名注册 + 实名同步 | 2～3 天 |
| 腾讯云初审 | 1～2 天 |
| 管局审核 | 1～3 周 |
| 公安备案 | 几天 |
| **合计** | **约 2～4 周** |
