# 阶段 1 云环境配置

本文用于部署“微信登录、加入申请和管理员审核”功能。任何初始化口令都只写入
云函数环境变量和开发者工具控制台，不写入代码、文档或 Git。

## 1. 创建数据库集合

在微信开发者工具的云开发控制台中创建以下集合：

- `users`
- `join_requests`

两个集合的安全规则均设置为小程序客户端不可直接读写。当前项目只允许 `api`
云函数访问数据库，所有身份和权限判断都在服务端完成。

## 2. 创建索引

在集合的“索引管理”中创建：

| 集合 | 索引字段 | 唯一 |
| --- | --- | --- |
| `users` | `openid` 升序 | 是 |
| `join_requests` | `applicant_id` 升序、`status` 升序 | 否 |
| `join_requests` | `status` 升序、`created_at` 降序 | 否 |

不要把 `join_requests.applicant_id + status` 设置为唯一索引，否则同一用户无法
保留多条历史拒绝记录。代码通过事务保证同一用户同时最多一条待审核申请。

## 3. 部署云函数

在项目根目录执行：

```powershell
npm run build:cloud
```

然后在微信开发者工具中右键 `cloudfunctions/api`，选择“上传并部署：云端安装依赖”。

## 4. 初始化首位所有者

1. 生成一个至少 16 字符的一次性随机口令，不要把口令发到聊天或提交到仓库。
2. 在云函数 `api` 的配置中新增环境变量：

   ```text
   OWNER_BOOTSTRAP_TOKEN=一次性随机口令
   ```

3. 重新部署或更新云函数配置。
4. 使用所有者本人的微信账号打开小程序。
5. 在微信开发者工具控制台执行：

   ```javascript
   wx.cloud.callFunction({
     name: 'api',
     data: {
       module: 'auth',
       action: 'bootstrapOwner',
       payload: { token: '填写一次性随机口令' },
     },
   }).then(({ result }) => console.log(result))
   ```

6. 只有返回 `ok: true` 且 `data.user.role` 为 `OWNER` 才表示初始化成功。
7. 初始化成功后立即删除 `OWNER_BOOTSTRAP_TOKEN` 环境变量。系统中已有所有者后，
   服务端也会拒绝再次初始化。

## 5. 人工验收

至少准备所有者账号和另一个微信账号：

1. 所有者重新登录后进入仓库工作台，并看到“成员审核”入口。
2. 第二个账号登录后填写姓名并提交加入申请。
3. 第二个账号重复提交时收到“已有一条待审核申请”提示。
4. 所有者在“成员审核”中拒绝申请。
5. 第二个账号修改姓名后可以重新申请。
6. 所有者通过申请后，第二个账号刷新并进入仓库工作台。
7. 第二个账号无法调用 `membership.listPendingJoinRequests`。
8. 将测试用户状态改为 `DISABLED` 后，该账号不能进入工作台。

阶段 1 只有在上述真机流程与自动化检查均通过后才算验收完成。
