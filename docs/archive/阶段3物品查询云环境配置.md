# 阶段 3 物品查询云环境配置

本文用于部署物品列表、文字搜索、分类筛选、游标分页和物品详情功能。

## 1. 数据库权限

确认以下集合的权限类型仍为“所有用户不可读写”：

- `items`
- `categories`
- `users`

小程序客户端只通过 `api` 云函数查询数据。云函数会再次校验当前微信账号必须为已审核成员。

## 2. 创建查询索引

在 `items` 的“索引管理”中确认原有 `code` 唯一索引仍存在，并新增：

| 索引名称 | 索引字段 | 唯一 |
| --- | --- | --- |
| `status_updated_id` | `status` 升序、`updated_at` 降序、`_id` 降序 | 否 |
| `category_status_updated_id` | `category_id` 升序、`status` 升序、`updated_at` 降序、`_id` 降序 | 否 |

第一条索引用于默认列表和文字搜索，第二条用于分类筛选。`updated_at` 与 `_id` 共同构成稳定分页顺序，
避免更新时间相同的物品在翻页时重复或遗漏。

云数据库如果在首次执行某种组合查询时返回“缺少索引”，应按错误详情给出的字段顺序补建索引，
不要删除现有索引或改成唯一索引。

## 3. 构建并部署云函数

在项目根目录执行：

```powershell
npm run build:cloud
```

然后在微信开发者工具中：

1. 右键 `cloudfunctions/api`；
2. 选择“上传并部署：云端安装依赖”；
3. 等待云函数状态变为“已部署”；
4. 重新编译小程序。

## 4. 接口快速验证

在微信开发者工具控制台执行：

```javascript
wx.cloud.callFunction({
  name: 'api',
  data: {
    module: 'items',
    action: 'list',
    payload: {
      keyword: '折叠桌',
      limit: 10
    }
  }
}).then(({ result }) => console.log(result))
```

预期返回 `ok: true`，`data.items` 中包含匹配名称、详情或公开编码的物品。

复制返回物品的 `id`，再执行：

```javascript
wx.cloud.callFunction({
  name: 'api',
  data: {
    module: 'items',
    action: 'detail',
    payload: {
      itemId: '替换为物品id'
    }
  }
}).then(({ result }) => console.log(result))
```

预期详情包含分类名称、登记人、最后修改人、登记时间、更新时间和版本。

## 5. 页面人工验收

1. 使用已审核账号进入“仓库工作台”，点击“文字搜索”。
2. 默认列表只显示 `ACTIVE` 和 `OUTBOUND_PENDING` 物品，按最后更新时间倒序排列。
3. 分别输入物品名称、详情关键词和公开编码，确认都能命中。
4. 连续快速修改关键词，最终结果必须与输入框中的最新关键词一致。
5. 选择分类后只显示该分类的物品，选择“全部分类”恢复完整列表。
6. 准备超过十条物品并滚动到底，确认加载下一页时没有重复或漏项。
7. 搜索不存在的内容，确认显示无结果状态。
8. 点击物品，确认最多两张图片、名称、详情、数量、分类、状态、版本和登记更新信息正确。
9. 停用一个已被物品引用的自定义分类：该分类不再出现在筛选器中，但对应物品仍可通过文字搜索打开，
   详情应标记分类“已停用”。
10. 使用未审核或已停用账号直接调用查询接口，确认返回无权限错误。

本批次不包含操作日志列表、编辑和离库申请，详情页暂不展示这些功能的空入口。
