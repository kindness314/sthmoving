# 阶段 3 小程序码云环境配置

本文用于部署物品小程序码生成、云存储、标签预览和扫码进入详情功能。

## 1. 创建数据库集合

在微信开发者工具的云开发控制台中创建：

- `item_labels`

权限类型选择“所有用户不可读写”。小程序客户端只能通过 `api` 云函数查询和生成标签。

## 2. 创建索引

在 `item_labels` 的“索引管理”中创建：

| 索引名称 | 索引字段 | 唯一 |
| --- | --- | --- |
| `item_id` | `item_id` 升序 | 是 |
| `public_code` | `public_code` 升序 | 是 |

`item_id` 唯一索引保证一个物品只有一条标签记录；`public_code` 唯一索引保证一个公开编码只绑定一个物品。
两个索引都不能创建为非唯一索引。

## 3. 配置云调用权限

`api` 云函数需要调用微信官方 `wxacode.getUnlimited` 接口。在云开发控制台中打开 `api` 云函数的
“云调用权限”或“权限配置”，确认已启用：

```text
wxacode.getUnlimited
```

不得把 AppSecret 或 `access_token` 写入代码、云函数环境变量或数据库。本项目使用微信云调用，
由微信平台处理接口凭证。

## 4. 开发版与正式版

当前代码在 `cloudfunctions/api/src/modules/labels.ts` 中明确配置：

```text
miniProgramCodeEnvironment = develop
```

因此本阶段生成的小程序码只用于开发者真机验证。正式打印实体标签前必须：

1. 将环境改为 `release`；
2. 上传并发布包含 `pages/item-detail/index` 的正式小程序；
3. 重新生成并覆盖开发版小程序码 PNG；
4. 再进行 T50 Pro 打印和实物扫码验收。

不能把开发版小程序码直接作为最终实体标签长期使用。

## 5. 构建并部署

在项目根目录执行：

```powershell
npm run build:cloud
```

然后在微信开发者工具中：

1. 右键 `cloudfunctions/api`；
2. 选择“上传并部署：云端安装依赖”；
3. 等待云函数状态变为“已部署”；
4. 重新编译小程序。

注意：部署本批次代码前必须先创建 `item_labels` 集合，否则新登记物品会因事务无法写入标签记录而失败。

## 6. 现有物品生成验证

1. 进入一个已有物品的详情页。
2. 点击“查看小程序码”。
3. 旧物品没有标签记录时，服务端应自动创建记录并生成小程序码。
4. `item_labels` 应新增一条记录，满足：
   - `item_id` 等于物品 `_id`；
   - `public_code` 等于 `items.code`；
   - `scene` 为 `i=<公开编码>`；
   - `page` 为 `pages/item-detail/index`；
   - `status` 为 `READY`；
   - `file_id` 指向 `labels/<itemId>/<publicCode>.png`。
5. 标签预览页应显示微信小程序码原始 PNG。
6. 再次进入预览页不应增加生成次数或创建第二条记录。

## 7. 新物品验证

1. 登记一个新物品。
2. 物品、首条操作日志和 `PENDING` 标签记录必须在同一事务中创建。
3. 登记成功后应进入标签预览页并自动生成小程序码。
4. 微信接口失败时，物品和日志必须保留，标签状态应为 `FAILED`。
5. 点击“重新生成”后继续使用原 `public_code`，不能创建第二条标签记录。

## 8. 扫码验证

1. 使用开发者微信账号在真机打开标签预览。
2. 使用另一台手机的微信“扫一扫”扫描屏幕上的小程序码。
3. 应打开 `pages/item-detail/index` 并显示对应物品。
4. 修改物品名称或数量后再次扫码，仍应打开同一物品并显示最新数据。
5. 无效 `scene` 应提示“无法识别该物品标签”。
6. 未审核或已停用账号不能通过扫码绕过成员权限。

开发版小程序码的可访问范围受开发者权限限制。本阶段只验证路由和数据绑定，不进行最终标签打印验收。

官方接口参数和限制见
[微信：获取不限制的小程序码](https://developers.weixin.qq.com/miniprogram/dev/server/API/qrcode-link/qr-code/api_getunlimitedqrcode.html)。
